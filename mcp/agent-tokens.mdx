A remote MCP credential grants an integration access to one cloud Bucket with a specific role. Your Bowerbirds workspace administrator supplies the endpoint and credential together.

## Choose a role

| Role | Use when |
| --- | --- |
| `read` | The integration only needs to inspect records and captures |
| `contribute` | The integration also needs to add findings |

Use the narrowest role that supports the workflow.

## Protect the credential

- Store it in the MCP client's secret storage or an environment variable.
- Do not commit it to source control.
- Do not paste it into support requests, screenshots, or shared documents.
- Ask the workspace administrator to revoke and replace it if it may have been exposed.

<Note>
  Remote access is available only for Buckets whose administrator has provisioned an integration credential.
</Note>
