Remote MCP is for hosted or off-device agents. A Bowerbirds workspace administrator supplies:

- the HTTPS MCP endpoint;
- a credential scoped to one Bucket;
- either `read` or `contribute` access.

<Warning>
  Do not use an infrastructure hostname or endpoint copied from development material. Use only the connection details supplied for your workspace.
</Warning>

## Configure an HTTP MCP client

Use the values supplied by the administrator:

```json
{
  "mcpServers": {
    "bowerbirds": {
      "type": "http",
      "url": "<BOWERBIRDS_MCP_URL>",
      "headers": {
        "Authorization": "Bearer ${BOWERBIRDS_AGENT_TOKEN}"
      }
    }
  }
}
```

Keep the credential in the client's secret storage or an environment variable rather than committing it with the configuration.

## Verify the scope

After connecting, ask the client to list records without making changes. Confirm that it can see only the intended Bucket before enabling a write-capable workflow.

## Fetching files

Remote capture tools return file metadata and authenticated download URLs. Fetch only the payload you need and send the same authorization credential when the client requests it.

See [Remote MCP tools](/mcp/remote-tools) for the supported tool surface.
