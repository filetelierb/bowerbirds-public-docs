Bowerbirds offers coding agents one MCP surface: the **remote MCP door** on Bowerbirds Cloud. An agent works the same cloud records a person sees in the apps, under the same rules, and every write is attributed to the agent's own token.

| | Remote MCP |
| --- | --- |
| Endpoint | `https://bowerbirds-cloud-y7wboabaoa-uc.a.run.app/mcp` over HTTPS |
| Credential | Obtained through OAuth in your browser, or a token minted by hand |
| Scope | One workspace (every Bucket in it) or one Bucket, with one role |
| Best for | Claude Code, Codex, Cursor and any MCP client that speaks OAuth |

<Note>
  The local stdio server (`bowerbirds mcp`) was retired on 2026-09-10. Clients configured for it must be pointed at the remote door; see [Connect a client](/mcp/remote-server).
</Note>

## Verify a connection

Ask the agent to call `list_items` on a Bucket without making changes. Every record it answers carries `signed: false` the first time; that field is the agent's own mark, explained in [Tools](/mcp/remote-tools#signatures).

## Capture permissions

An agent never captures the screen or microphone. Captures are taken by a person in the Bowerbirds apps; the agent reads what was filed and files what it produces.
