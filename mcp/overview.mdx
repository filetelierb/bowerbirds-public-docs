Bowerbirds supports two MCP connection types.

| | Local MCP | Remote MCP |
| --- | --- | --- |
| Runs from | The Mac with Bowerbirds installed | A hosted Bowerbirds endpoint |
| Connection | `bowerbirds mcp` over stdio | HTTPS |
| Scope | Filed local Buckets | One approved cloud Bucket |
| Best for | Desktop agents and rich local workflows | Hosted or off-device agents |

## Verify a connection

For a local connection, ask the client to call `get_server_info` and `list_buckets`. For a remote connection, ask it to list the records in the Bucket it was granted.

## Capture permissions

MCP cannot silently capture the screen or microphone. Local clients can create a visible one-time request that the person must approve in Bowerbirds.
