---
title: "Local MCP tools"
description: "The supported tools exposed by the local Bowerbirds MCP connection."
icon: "toolbox"
---

Available tools may vary by Bowerbirds version. Call `get_server_info` after connecting and use the tool definitions returned by your MCP client as the exact contract.

## Discover and organize

| Tool | Purpose |
| --- | --- |
| `get_server_info` | Report the connected version and capabilities |
| `list_buckets` | List filed Buckets |
| `list_directories` | List directories in a Bucket |
| `get_bucket` | Read a Bucket and its records |
| `get_directory` | Read a directory and its records |
| `create_bucket` | Create a Bucket |
| `create_directory` | Create a directory |
| `move_directory` | Move a directory inside its Bucket |
| `get_item` | Read one record |
| `search_items` | Search filed records |
| `remove_item` | Move a record to Trash |
| `export_bucket` | Export a Bucket as Markdown |

## Files and captures

| Tool | Purpose |
| --- | --- |
| `list_item_files` | List a record's payloads |
| `get_item_payload` | Fetch one payload |
| `captures_list` | List recent filed captures |
| `capture_read` | Read a capture and preview images |
| `capture_export` | Export a complete capture to disk |
| `add_item` | Add text context |
| `add_file_item` | Add a small file supplied by the client |
| `import_local_file` | Import an existing local path |
| `add_image_item` | Add an image supplied by the client |

Prefer `import_local_file` when another tool already created a file on disk.

## Scratchpads and Packages

| Tool | Purpose |
| --- | --- |
| `create_scratchpad` | Create an editable document |
| `get_scratchpad` | Read a Scratchpad and its revision |
| `update_scratchpad` | Replace or append content with revision protection |
| `scratchpad_from_dictation` | Create an editable document from a Dictation |
| `list_packages` | List Packages in a Bucket |
| `get_package` | Read a Package |
| `validate_package` | Validate a Package before saving |
| `upsert_package` | Create or update a Package |

Read the Package-authoring MCP resource before constructing Package data, and validate before saving.

## Human approval

| Tool | Purpose |
| --- | --- |
| `notify_user` | Show a local notification |
| `request_input` | Ask for structured human input |
| `request_capture_authorization` | Request one visible capture |
| `await_response` | Wait for the person's decision or response |
| `cancel_request` | Cancel a pending request |

<Note>
  Read before writing. Do not create, move, update, or remove records unless the user requested that change.
</Note>
