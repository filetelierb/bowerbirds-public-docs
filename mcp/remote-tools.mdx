---
title: "Remote MCP tools"
description: "The supported tools for an approved Bucket-scoped remote connection."
icon: "cloud-arrow-up"
---

Remote MCP exposes a deliberately small surface for one shared Bucket.

## `list_items`

Lists the records available to the connection. It does not include file bytes.

```json
{}
```

## `list_captures`

Lists recent captures. Use optional filters only when supported by the tool definition shown in your MCP client.

```json
{
  "limit": 20
}
```

## `get_capture`

Returns one capture and its file metadata.

```json
{
  "item_id": "<record-id>"
}
```

Download URLs require the same authorization credential as the MCP connection.

## `add_finding`

Adds a text finding when the connection has `contribute` access.

```json
{
  "title": "Checkout regression",
  "content": "The address form loses its country value after validation."
}
```

<Note>
  Use local MCP for richer file, Scratchpad, Package, and human-approval workflows.
</Note>
