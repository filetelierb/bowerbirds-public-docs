---
title: "Local MCP server"
description: "Connect an MCP client to Bowerbirds on the same Mac."
icon: "laptop"
---

The Bowerbirds macOS app includes a local MCP server. Use its absolute path so the client starts the expected installation.

```text
/Applications/Bowerbirds.app/Contents/Helpers/bowerbirds
```

## Sign in

```sh
'/Applications/Bowerbirds.app/Contents/Helpers/bowerbirds' cloud login
```

## Connect a client

<Tabs>
  <Tab title="Codex">
    ```sh
    codex mcp add bowerbirds -- \
      '/Applications/Bowerbirds.app/Contents/Helpers/bowerbirds' mcp
    ```
  </Tab>
  <Tab title="Claude Code">
    ```sh
    claude mcp add bowerbirds -- \
      '/Applications/Bowerbirds.app/Contents/Helpers/bowerbirds' mcp
    ```
  </Tab>
  <Tab title="JSON configuration">
    ```json
    {
      "mcpServers": {
        "bowerbirds": {
          "command": "/Applications/Bowerbirds.app/Contents/Helpers/bowerbirds",
          "args": ["mcp"]
        }
      }
    }
    ```
  </Tab>
</Tabs>

Restart clients that cache MCP processes after updating Bowerbirds or changing the configuration.

## Verify the connection

Ask the client:

> Call `get_server_info`, list my Bowerbirds Buckets, and tell me which tools are available. Do not change anything.

If a record is visible in the app but not through MCP, make sure it has been filed into a Bucket rather than left in Unsorted.
