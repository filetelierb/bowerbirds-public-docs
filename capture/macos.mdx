The macOS app owns the permissioned capture capabilities that are unavailable to headless tools.

## Control bar

Hold the configured trigger for two seconds to arm the current mode. The default trigger is **Fn**.

- While arming, use **Left/Right** to switch modes.
- Use **Up/Down** or scroll for the current mode's inner choice: Dictation tuning, a Scratchpad/Vision template, Capture history, or Recording sources.
- Double-tap the trigger for an instant Capture, Vision, or Recording action.
- Double-click the bar to move it between bottom-center and bottom-right.

The trigger can be changed to a right-side modifier or modifier chord in Capture Preferences.

## Modes

| Mode | Result |
| --- | --- |
| Dictation | Transcribed text delivered to the active app; successful dictations are not filed as records |
| Scratchpad | Mutable, revisioned working document |
| Capture | Screenshot with mask-first annotation tools and numbered comments |
| Vision | Region-based visual conversation; copied answers can be filed |
| Recording | Any non-empty combination of microphone, device audio, and screen |

Recording can combine microphone, device audio, and screen. Screen recordings use the native macOS content picker. Notes, transcripts, Packages, and altered recordings are optional later outputs.

<Note>
  A failed Dictation keeps its exact audio locally for 72 hours so it can be retried or discarded. A successful Dictation is pasted or otherwise delivered and is not saved as a Bowerbirds record.
</Note>

## Quick Blink

Quick Blink is a post-processing action on a filed screen recording, not a sixth capture mode. Open a recording, choose a span, and review frames around visual changes. No AI is used and nothing leaves the device. Saving creates a separate Package and leaves the recording untouched.

## Fixed shortcuts

| Shortcut | Action |
| --- | --- |
| **Control–Option–T** | Capture the main display into the current destination |
| **Control–Option–N** | Activate Bowerbirds and focus a new Quick Note |
| **Shift–Command–V** | Paste the latest filed artifact |

Global shortcuts and pasting may require Accessibility permission.

## Recording privacy

The screen source uses the native macOS picker, so the person chooses which display, application, or window is recorded. Microphone and screen recording require their respective system permissions. Processing never replaces the original recording; an altered recording is written as a new payload.
