This walkthrough creates one local Bucket, adds a note, syncs it, and connects an AI client over MCP.

<Info>
  Bowerbirds currently supports macOS 14 or later. The iOS app captures and reviews context, but the CLI runs on Mac.
</Info>

<Steps>
  <Step title="Locate the Bowerbirds CLI">
    The macOS app includes the CLI used by scripts:

    ```sh
    export BOWERBIRDS_CLI='/Applications/Bowerbirds.app/Contents/Helpers/bowerbirds'
    "$BOWERBIRDS_CLI" server info
    ```

    If you installed the app elsewhere, update the path.
  </Step>
  <Step title="Sign in">
    Sign in once before using authenticated cloud commands.

    ```sh
    "$BOWERBIRDS_CLI" cloud login
    ```

    If the packaged app is already signed in, this session is shared and you can continue.
  </Step>
  <Step title="Create a Bucket">
    ```sh
    "$BOWERBIRDS_CLI" bucket create payments-bug \
      -d "Checkout investigation"
    ```

    Bucket names are slugified. Use the returned slug in later commands.
  </Step>
  <Step title="Add context">
    ```sh
    "$BOWERBIRDS_CLI" add text payments-bug \
      "Checkout fails after address validation." \
      --title "Observed behavior" \
      --tags checkout,bug

    "$BOWERBIRDS_CLI" import payments-bug \
      /absolute/path/to/checkout-error.png \
      --title "Checkout error" \
      --json
    ```

    Images imported without an explicit type become `capture` records. Videos become `recording` records.
  </Step>
  <Step title="Check what was stored">
    ```sh
    "$BOWERBIRDS_CLI" bucket show payments-bug --json
    ```
  </Step>
  <Step title="Sync the Bucket">
    Agents work with cloud records, so push the Bucket:

    ```sh
    "$BOWERBIRDS_CLI" cloud push payments-bug
    ```
  </Step>
  <Step title="Connect an MCP client">
    Pick your client. This Claude Code command is the shortest path:

    ```sh
    claude mcp add --transport http bowerbirds \
      https://bowerbirds-cloud-y7wboabaoa-uc.a.run.app/mcp
    ```

    For ChatGPT/Codex, Cursor, Antigravity, or the plugins, open [Client integrations](/integrations/overview).
  </Step>
  <Step title="Run the smoke test">
    Restart the client if it was already open, then ask:

    > Use Bowerbirds. List the records in my `payments-bug` Bucket and summarize them. Do not change anything.

    The first call opens the approval page in your browser: sign in, pick the workspace and the `read` role, and approve. A working connection calls `list_items` and `get_capture` and finds the note and image you added.
  </Step>
</Steps>

<Note>
  Keep Bowerbirds installed for capture, review, and other interactive actions. An agent acts with the role you approved, never as you, and you can revoke it from Settings → Developer Tools.
</Note>
