## Buckets and directories

A **Bucket** is the top-level unit you organize, sync, share, or grant to an integration. Directories organize records inside a Bucket.

```sh
bowerbirds bucket create "Payments bug"
bowerbirds directory create payments-bug "Browser evidence"
bowerbirds directory list payments-bug --json
```

Commands use Bucket and directory slugs returned by Bowerbirds.

## Records and payloads

A **record** is one durable piece of context, such as a capture, recording, note, Scratchpad, or imported file.

A record can have one or more **payloads**. These are the files associated with it—for example, an original screenshot, an annotated image, audio, video, or a document. List a record's payloads before fetching one instead of guessing its filename.

## Unsorted and Trash

**Unsorted** is private staging on one device. CLI listings, exports, and MCP connections do not enumerate it. File a record into a Bucket when it should be available to scripts or agents.

**Trash** is recoverable until it is emptied.

## Packages

A **Package** is an ordered collection of records and visual scenes used for handoffs, reviews, demos, or guides. Creating a Package does not alter its source records.

Use the Package tools to create, validate, and retrieve one. See [Build a Package](/workflows/packages).
