## Private by default

- Content in **Unsorted** stays private to the device and is not exposed through MCP.
- Cloud sync is enabled only for selected Buckets.
- Normal removal sends records to recoverable Trash.
- Original captures remain separate from annotations and other derived outputs.

## Capture remains user-controlled

Scripts and agents do not inherit screen or microphone permission. A supported agent workflow may request a one-time capture, but Bowerbirds shows the request and the person can approve, decline, review, or cancel it.

## Use the narrowest access

Local integrations run with the signed-in person's Bowerbirds access. Remote integrations are limited to the Bucket and role selected by its administrator.

- Use **read** for integrations that only inspect context.
- Use **contribute** only when the integration needs to add findings.
- Store connection credentials in the client's secret storage or an environment variable.
- Revoke credentials when an integration is retired or a secret may have been exposed.

<Warning>
  Never commit a Bowerbirds connection credential to source control or place it in a shared project configuration.
</Warning>
