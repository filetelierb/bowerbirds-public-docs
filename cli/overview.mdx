The `bowerbirds` CLI shares the app's local store and also provides explicit authenticated cloud commands.

## Locate the executable

The macOS app includes the CLI at:

```sh
'/Applications/Bowerbirds.app/Contents/Helpers/bowerbirds' server info
```

Add a shell alias if you want to invoke it as `bowerbirds` from anywhere.

## Local versus cloud

```sh
# Local Buckets
bowerbirds buckets --json
bowerbirds bucket show research --json

# Authenticated Bowerbirds Cloud
bowerbirds cloud login
bowerbirds cloud whoami
bowerbirds cloud buckets list
```

## Machine-readable output

Add `--json` to supported commands. JSON mode is the recommended contract for scripts; human output is intentionally optimized for the terminal and may include guidance text.

```sh
bowerbirds item show research 01J... --json | jq '.item.title'
```

## JSON output

Use `--json` only on commands that advertise it in `bowerbirds help`. Commands that follow long-running work may emit newline-delimited JSON events instead of one document.
