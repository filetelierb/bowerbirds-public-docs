Add `--json` to supported commands. Arguments in angle brackets are required.

## Server and organization

```text
bowerbirds server info
bowerbirds buckets
bowerbirds bucket create <name> [-d description]
bowerbirds bucket show <slug>
bowerbirds bucket rename <slug> <name>
bowerbirds bucket delete <slug>
bowerbirds bucket export <slug> [--md file]
bowerbirds bucket fetch <slug> --out <directory>
bowerbirds directory list <bucket-slug>
bowerbirds directory create <parent-slug> <name> [-d description]
bowerbirds directory move <directory-slug> --parent <parent-slug>
bowerbirds directory show <directory-slug>
bowerbirds directory rename <directory-slug> <name>
bowerbirds directory delete <directory-slug>
```

## Records, files, and Trash

```text
bowerbirds item show <slug> <item-id>
bowerbirds item files <slug> <item-id>
bowerbirds item fetch <slug> <item-id> <payload-name> --out <path>
bowerbirds item submit <slug> <path> [options]
bowerbirds item remove <slug> <item-id>
bowerbirds import <slug> <path> [options]
bowerbirds add text <slug> <text> [--title title] [--tags a,b]
bowerbirds add file <slug> <path> [options]
bowerbirds image submit <slug> <png-or-jpeg> [options]
bowerbirds trash list
bowerbirds trash restore <item-id> [item-id ...]
bowerbirds trash empty [--older-than-days N]
```

File options include `--title`, `--content`, `--mime`, `--role`, `--tags`, and where supported `--type capture|recording|file`.

## Scratchpads

```text
bowerbirds scratchpad list <slug>
bowerbirds scratchpad create <slug> <title> [--content text]
bowerbirds scratchpad show <slug> <item-id>
bowerbirds scratchpad history <slug> <item-id>
bowerbirds scratchpad improve <item-id> --instruction <text> [--content <draft>]
bowerbirds scratchpad update <slug> <item-id> --revision <n> --content <text> [options]
bowerbirds scratchpad append <slug> <item-id> --revision <n> --content <text> [options]
bowerbirds scratchpad from-dictation <slug> <item-id> [--title title]
bowerbirds vision follow-up <item-id> --text <question>
```

## Captures and Packages

```text
bowerbirds capture list [--bucket slug] [--limit N]
bowerbirds capture export <item-id> [--out <directory>]
bowerbirds package list <slug>
bowerbirds package create <slug> <title> [--summary text]
bowerbirds package fetch <slug> <item-id> --out <path>
bowerbirds package validate <slug> <item-id>
```

## Cloud

```text
bowerbirds cloud login
bowerbirds cloud logout
bowerbirds cloud whoami
bowerbirds cloud devices
bowerbirds cloud signout-all
bowerbirds cloud orgs [list|use|members]
bowerbirds cloud buckets [list|create|delete]
bowerbirds cloud push <bucket-slug> [--to owner/slug]
bowerbirds cloud pull <owner/slug> [--as local-name]
bowerbirds cloud sync <bucket-slug> [on|off]
bowerbirds cloud share <slug> <email> [--role read|contribute|admin]
bowerbirds cloud capture <owner>/<slug>/<item-id> [--out directory]
bowerbirds cloud captures <owner>/<slug> [--limit N] [--since RFC3339]
bowerbirds cloud recording process <bucket-slug> <item-id> --template <id> [--frames seconds,...] [--follow]
bowerbirds cloud records <list|payload|search|show|move|trash|sign|unsign|push-capture|edit-text|copy>
bowerbirds cloud records list <owner/slug[/path]> [--exact] [--kind a,b] [--since RFC3339] [--signed|--unsigned] [--limit N] [--cursor c]
bowerbirds cloud records push-capture <owner/slug[/path]> --image <png|jpg> [--original <png>] [--session <json>] [--title t] [--content text] [--tags a,b]
bowerbirds cloud records sign|unsign <owner/slug> --ids <id,id>
bowerbirds cloud records move <owner/slug[/path]> --ids <id,id> --to <owner/slug[/path]>
bowerbirds cloud records trash <owner/slug> --ids <id,id>
bowerbirds cloud tokens login [--scope read|contribute|admin] [--no-browser]
bowerbirds cloud tokens logout
bowerbirds cloud tokens status
bowerbirds cloud tokens mint --label <label> --role read|contribute|admin [--bucket <owner/slug>]
bowerbirds cloud tokens list [--bucket <owner/slug>]
bowerbirds cloud tokens revoke <id> [--bucket <owner/slug>]
bowerbirds cloud flows <list|show|run|apply>
bowerbirds cloud rfis <list|answer>
bowerbirds cloud web-captures <list|mint|rename|origins|set-disabled|set-recording|reveal|rotate|delete|restore>
bowerbirds cloud usage
```

Use `--org <id-or-slug>` with cloud commands to target a workspace without switching. Add `--token <bbt_…>` (or set `BOWERBIRDS_TOKEN`) to act as an agent token instead of the signed-in person; a `tokens login` credential is used when neither is set.

## MCP

There is no local MCP server. Agents connect to the remote door; see [MCP overview](/mcp/overview).

Run `bowerbirds help` or `bowerbirds <command> --help` for options supported by your installed version.
