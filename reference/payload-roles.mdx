---
title: "Working with record files"
description: "List, choose, and fetch the files attached to a Bowerbirds record."
icon: "file"
---

A record can contain multiple files, such as an original screenshot, an annotated image, audio, video, or a document.

## List before fetching

Use `list_item_files` or `bowerbirds item files` before requesting a file. Keep the exact file name returned by Bowerbirds rather than guessing it.

```sh
bowerbirds item files research <record-id> --json
bowerbirds item fetch research <record-id> <file-name> --out ./download
```

## Choose by purpose

When the response includes a semantic role, use it to choose the file that matches the task—for example, the original capture, the reviewed annotated image, or the primary recording. Preserve files with unfamiliar roles when copying or exporting a record.

## Large files

For large or complete capture sets, prefer CLI export, or the short-lived payload URLs the remote MCP door answers, instead of moving file bytes through model context.
