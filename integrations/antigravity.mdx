Antigravity 2.0, the IDE, and Antigravity CLI read global MCP configuration from `~/.gemini/config/mcp_config.json`.

## Local Bowerbirds

```json
{
  "mcpServers": {
    "bowerbirds": {
      "command": "/Applications/Bowerbirds.app/Contents/Helpers/bowerbirds",
      "args": ["mcp"]
    }
  }
}
```

## One cloud Bucket

Antigravity's remote shape uses `serverUrl`:

```json
{
  "mcpServers": {
    "bowerbirds-cloud": {
      "serverUrl": "https://bowerbirds-cloud-y7wboabaoa-uc.a.run.app/mcp",
      "headers": {
        "Authorization": "Bearer bbt_REPLACE_ME"
      }
    }
  }
}
```

<Warning>
  This file contains the token in cleartext. Restrict its permissions, never commit it, and prefer the local connection when Antigravity runs on the same Mac. Rotate the token if the file is exposed.
</Warning>

Restart Antigravity after editing the file, then inspect the MCP server list and ask it to list the connected Bucket's captures.

See Google's [Antigravity MCP setup](https://codelabs.developers.google.com/getting-started-google-antigravity) for client-level settings.
