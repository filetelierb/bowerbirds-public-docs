---
title: "Antigravity"
description: "Connect Google Antigravity IDE or CLI to the Bowerbirds remote MCP door."
icon: "satellite"
---

Add Bowerbirds to Antigravity's MCP configuration. If Antigravity cannot run the OAuth approval, present a token minted by hand (see [Agent tokens](/mcp/agent-tokens)):

```json
{
  "mcpServers": {
    "bowerbirds": {
      "url": "https://bowerbirds-cloud-y7wboabaoa-uc.a.run.app/mcp",
      "headers": {
        "Authorization": "Bearer ${BOWERBIRDS_AGENT_TOKEN}"
      }
    }
  }
}
```

Store the token outside shared configuration and source control. Restart Antigravity after saving the file, then inspect its MCP server list and ask it to list a Bucket's records.

See Google's [Antigravity MCP setup](https://codelabs.developers.google.com/getting-started-google-antigravity) for the current configuration location and client-level settings.
