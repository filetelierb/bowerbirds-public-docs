---
title: "Antigravity"
description: "Connect Google Antigravity IDE or CLI to Bowerbirds over local MCP."
icon: "satellite"
---

Add Bowerbirds to Antigravity's MCP configuration:

```json
{
  "mcpServers": {
    "bowerbirds": {
      "command": "/Applications/Bowerbirds.app/Contents/Helpers/bowerbirds",
      "args": ["mcp"]
    }
  }
}
```

Restart Antigravity after saving the file, then inspect its MCP server list and ask it to call `get_server_info`.

For an approved remote connection, use the endpoint and credential supplied by your Bowerbirds workspace administrator. Store the credential outside shared configuration and source control.

See Google's [Antigravity MCP setup](https://codelabs.developers.google.com/getting-started-google-antigravity) for the current configuration location and client-level settings.
