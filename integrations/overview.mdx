Bowerbirds uses standard MCP over HTTPS. Every client connects to the same remote door and approves the connection in your browser; no client runs anything on your Mac.

```text
https://bowerbirds-cloud-y7wboabaoa-uc.a.run.app/mcp
```

| Client | Connection | Setup |
| --- | --- | --- |
| Claude Code | Remote HTTP with OAuth | `claude mcp add --transport http` |
| Claude Desktop | Remote HTTP with OAuth | Desktop MCP configuration |
| ChatGPT desktop / Codex | Remote HTTP with OAuth | MCP settings or `codex mcp add` |
| Cursor | Remote HTTP with OAuth | `mcp.json` |
| Antigravity | Remote HTTP with a minted token | `mcp_config.json` |

<Info>
  The [Bowerbirds plugins](/integrations/plugins) bundle the endpoint and a skill for Claude Code and Codex. Marketplace installation becomes available once the repository is published.
</Info>

## Verify any client

After connecting, ask the agent:

> Use Bowerbirds. List the records in my `<bucket>` Bucket and summarize them. Do not write or delete anything.

The first call opens the approval page in your browser. If the tool list is missing, restart the client after saving its MCP configuration.
