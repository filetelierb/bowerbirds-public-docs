Bowerbirds uses standard MCP, but clients package MCP connections differently. Start with the row that matches where your agent runs.

| Client | Best connection today | Install experience | Status |
| --- | --- | --- | --- |
| Claude Code | Local stdio | Bowerbirds plugin or one CLI command | Ready |
| Claude Desktop | Local stdio | Desktop MCP configuration | Ready |
| ChatGPT desktop / Codex | Local stdio | Shared MCP settings or Codex plugin | Ready |
| Cursor | Local stdio; remote HTTP when needed | Bowerbirds plugin or `.cursor/mcp.json` | Ready |
| Antigravity | Local stdio; remote HTTP when needed | `mcp_config.json` | Ready |
| ChatGPT web | Remote HTTP plugin | Public plugin requires OAuth 2.1 | Blocked on cloud auth |

## Local or remote?

<CardGroup cols={2}>
  <Card title="Local MCP" icon="laptop" href="/mcp/local-server">
    Use on the Mac running Bowerbirds. It exposes rich read/write tools across filed local Buckets.
  </Card>
  <Card title="Remote MCP" icon="cloud" href="/mcp/remote-server">
    Use from another machine or hosted agent. One `bbt_` token opens exactly one cloud Bucket.
  </Card>
</CardGroup>

Local MCP is the best first experience. It can import local files, work with Packages and Scratchpads, and request human input. Remote MCP intentionally exposes only a small bucket-scoped surface.

<Warning>
  Two product gaps affect remote onboarding: the apps and CLI do not yet mint `bbt_` agent tokens, and Bowerbirds Cloud does not yet implement the OAuth 2.1 flow required for a public ChatGPT plugin. A Bucket administrator or backend operator must currently provision remote tokens.
</Warning>

## What “plugin” means here

- **Claude Code, Codex, and Cursor:** this repository contains client manifests around one shared plugin with an MCP connection and Bowerbirds workflow guidance.
- **Antigravity:** this client currently uses an MCP configuration file for Bowerbirds.
- **ChatGPT web:** a public plugin is a hosted remote MCP integration submitted to the ChatGPT plugin directory. Bowerbirds needs OAuth before it can be submitted safely.

## Verify any client

After connecting, ask the agent:

> Call `get_server_info`, list my Bowerbirds Buckets, and tell me which tools you can use. Do not write or delete anything.

If `get_server_info` is unavailable, the client is probably connected to the remote server. If every local tool reports an authentication error, open Bowerbirds and sign in again.
