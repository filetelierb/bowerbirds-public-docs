Bowerbirds uses standard MCP. The supported public setup today is a local MCP connection to the CLI included with the macOS app.

| Client | Connection | Setup |
| --- | --- | --- |
| Claude Code | Local stdio | `claude mcp add` |
| Claude Desktop | Local stdio | Desktop MCP configuration |
| ChatGPT desktop / Codex | Local stdio | MCP settings or `codex mcp add` |
| Cursor | Local stdio | `mcp.json` |
| Antigravity | Local stdio | `mcp_config.json` |

<Info>
  Marketplace plugins are not currently distributed publicly. Use the standard MCP setup in the client guides below.
</Info>

Approved hosted agents can also use remote MCP. Your workspace administrator must supply the endpoint and scoped credential; infrastructure URLs found elsewhere are not supported connection details.

## Verify any local client

After connecting, ask the agent:

> Call `get_server_info`, list my Bowerbirds Buckets, and tell me which tools you can use. Do not write or delete anything.

If the tool list is missing, restart the client after saving its MCP configuration. If a record is missing, make sure it is filed into a Bucket rather than left in Unsorted.
