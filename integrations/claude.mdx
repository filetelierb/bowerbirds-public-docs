## Claude Code plugin

The Bowerbirds repository includes a Claude Code marketplace package. In Claude Code, run:

```text
/plugin marketplace add filetelierb/bowerbirds-public-docs
/plugin install bowerbirds@bowerbirds
```

Restart Claude Code after installation. The plugin finds the CLI at `/Applications/Bowerbirds.app/Contents/Helpers/bowerbirds`. For a development build, launch Claude Code with `BOWERBIRDS_CLI` set to the executable path.

The plugin bundles two things:

- the local `bowerbirds mcp` connection;
- agent guidance for navigating Buckets, payloads, Packages, and human-in-the-loop capture requests.

## One-command setup

If you do not want the plugin, add only the MCP server:

```sh
claude mcp add bowerbirds -- \
  '/Applications/Bowerbirds.app/Contents/Helpers/bowerbirds' mcp
```

Inspect it with `claude mcp list`.

## Claude Desktop

Add a local stdio server named `bowerbirds` with:

```json
{
  "command": "/Applications/Bowerbirds.app/Contents/Helpers/bowerbirds",
  "args": ["mcp"]
}
```

Restart Claude Desktop after saving the server. If your Claude Desktop build supports MCP extensions, the repository plugin is still intended for Claude Code; a signed `.dxt` package is not published yet.

## Remote connection

Claude Code can also reach one cloud Bucket:

```sh
export BOWERBIRDS_AGENT_TOKEN='bbt_...'
claude mcp add --transport http bowerbirds-cloud \
  https://bowerbirds-cloud-y7wboabaoa-uc.a.run.app/mcp \
  --header "Authorization: Bearer $BOWERBIRDS_AGENT_TOKEN"
```

See [Agent tokens](/mcp/agent-tokens) before sharing or rotating the secret.

See Anthropic's [Claude Code plugin](https://code.claude.com/docs/en/plugins) and [MCP](https://code.claude.com/docs/en/mcp) documentation for client-level settings.
