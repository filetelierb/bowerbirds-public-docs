## Claude Code

```sh
claude mcp add bowerbirds -- \
  '/Applications/Bowerbirds.app/Contents/Helpers/bowerbirds' mcp
```

Run `claude mcp list` to confirm the connection, then restart Claude Code if it was already open.

## Claude Desktop

Add a local stdio server named `bowerbirds`:

```json
{
  "command": "/Applications/Bowerbirds.app/Contents/Helpers/bowerbirds",
  "args": ["mcp"]
}
```

Restart Claude Desktop after saving the configuration.

## Verify

Ask Claude to call `get_server_info` and `list_buckets` without making changes.

For an approved remote connection, use the endpoint and credential supplied by your Bowerbirds workspace administrator. See [Remote MCP connection](/mcp/remote-server).

See Anthropic's [MCP documentation](https://code.claude.com/docs/en/mcp) for client-level settings.
