## Claude Code

```sh
claude mcp add --transport http bowerbirds \
  https://bowerbirds-cloud-y7wboabaoa-uc.a.run.app/mcp
```

Run `claude mcp list` to confirm the connection. The first tool call opens the approval page in your browser: sign in, pick the organization and the role, and approve.

The [Bowerbirds plugin](/integrations/plugins) adds the same server together with a skill and a `/bowerbirds-triage` command.

## Claude Desktop

Add a remote server named `bowerbirds`:

```json
{
  "type": "http",
  "url": "https://bowerbirds-cloud-y7wboabaoa-uc.a.run.app/mcp"
}
```

Restart Claude Desktop after saving the configuration and complete the approval when it opens.

## Verify

Ask Claude to list a Bucket's records without making changes.

See Anthropic's [MCP documentation](https://code.claude.com/docs/en/mcp) for client-level settings.
