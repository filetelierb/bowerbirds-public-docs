---
title: "Cursor"
description: "Connect a Cursor project to the Bowerbirds remote MCP door."
icon: "code"
---

Create `.cursor/mcp.json` in a project for project-scoped access, or use `~/.cursor/mcp.json` for all projects:

```json
{
  "mcpServers": {
    "bowerbirds": {
      "url": "https://bowerbirds-cloud-y7wboabaoa-uc.a.run.app/mcp"
    }
  }
}
```

Restart Cursor or run **Developer: Reload Window**, then confirm that the Bowerbirds server is enabled in MCP settings. Cursor opens the approval page in your browser when it first connects.

See Cursor's [MCP documentation](https://cursor.com/docs/mcp) for client-level settings and diagnostics.
