---
title: "Cursor"
description: "Connect a Cursor project to the local Bowerbirds MCP server."
icon: "code"
---

Create `.cursor/mcp.json` in a project for project-scoped access, or use `~/.cursor/mcp.json` for all projects:

```json
{
  "mcpServers": {
    "bowerbirds": {
      "command": "/Applications/Bowerbirds.app/Contents/Helpers/bowerbirds",
      "args": ["mcp"]
    }
  }
}
```

Restart Cursor or run **Developer: Reload Window**, then confirm that the Bowerbirds server and tools are enabled in MCP settings.

For an approved remote connection, use the endpoint and credential supplied by your Bowerbirds workspace administrator. Keep the credential out of project files and source control.

See Cursor's [MCP documentation](https://cursor.com/docs/mcp) for client-level settings and diagnostics.
