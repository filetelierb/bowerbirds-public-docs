## Codex CLI

```sh
codex mcp add bowerbirds --url https://bowerbirds-cloud-y7wboabaoa-uc.a.run.app/mcp
codex mcp list
```

The first tool call opens the approval page in your browser. The [Bowerbirds plugin](/integrations/plugins) packages the same server with a skill as an Agent Plugin.

## ChatGPT

Enable developer mode in ChatGPT's settings and add the endpoint as a remote MCP server. ChatGPT runs the OAuth approval when it first connects.

## Verify

Ask the client to list a Bucket's records without making changes.

See the official OpenAI documentation for [Codex MCP configuration](https://learn.chatgpt.com/docs/extend/mcp?surface=cli).
