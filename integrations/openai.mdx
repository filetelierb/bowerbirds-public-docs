## ChatGPT desktop

In the desktop app's MCP settings, add a local stdio server named `bowerbirds` with:

```text
/Applications/Bowerbirds.app/Contents/Helpers/bowerbirds mcp
```

Save the configuration and restart the client if needed.

## Codex CLI

```sh
codex mcp add bowerbirds -- \
  '/Applications/Bowerbirds.app/Contents/Helpers/bowerbirds' mcp
codex mcp list
```

## Verify

Ask the client to call `get_server_info` and `list_buckets` without making changes.

<Note>
  A public ChatGPT web integration is not currently available. Use a supported desktop MCP client, or an approved remote connection supplied by your Bowerbirds workspace administrator.
</Note>

See the official OpenAI documentation for [Codex MCP configuration](https://learn.chatgpt.com/docs/extend/mcp?surface=cli).
